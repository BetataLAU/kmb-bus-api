我們要用的 API：KMB 實時到站資料

由九龍巴士（KMB）及龍運巴士（LWB）提供的 RESTful API，回傳 JSON 格式。所有端點共用同一個 Base URL：

GET https://data.etabus.gov.hk/v1/transport/kmb/route/

它提供 9 個主要端點（Endpoint）：

功能Endpoint（路徑）
全部路線清單/v1/transport/kmb/route/
指定路線資料/v1/transport/kmb/route/{route}/{direction}/{service_type}
全部站點清單/v1/transport/kmb/stop
指定站點資料/v1/transport/kmb/stop/{stop_id}
指定路線的站點序列/v1/transport/kmb/route-stop/{route}/{direction}/{service_type}
某站＋某路線的到站時間/v1/transport/kmb/eta/{stop_id}/{route}/{service_type}
某站所有路線的到站時間/v1/transport/kmb/stop-eta/{stop_id}
某路線全程的到站時間/v1/transport/kmb/route-eta/{route}/{service_type}

完整說明請看 API 文件。
